**Chroniton Labs** publishes open source projects for distributed data and streaming systems. [AxonOps](https://axonops.com) is the steward. Find out more at [chronitonlabs.org](https://chronitonlabs.org).

## Projects

<img src="https://github.com/chronitonlabs/brand/raw/main/chronitondb/chronitondb-icon-charcoal-512.png" width="56" align="left" alt="ChronitonDB mark">

**[ChronitonDB](https://chronitonlabs.org/projects/chronitondb/)**, an open source database built on [Apache Cassandra](https://cassandra.apache.org/)®. In early development and not ready to use yet. [Repository](https://github.com/chronitonlabs/chronitondb)

<br clear="left"/>

<img src="https://github.com/chronitonlabs/brand/raw/main/chronitonmq/chronitonmq-icon-charcoal-512.png" width="56" align="left" alt="ChronitonMQ mark">

**[ChronitonMQ](https://chronitonlabs.org/projects/chronitonmq/)**, a message broker written in Rust that works with [Apache Kafka](https://kafka.apache.org/)® clients. Coming soon.

<br clear="left"/>

<img src="https://github.com/chronitonlabs/brand/raw/main/cqlai/cqlai-icon-charcoal-512.png" width="56" align="left" alt="CQLAI mark">

**[CQLAI](https://chronitonlabs.org/projects/cqlai/)**, a CQL shell with optional AI assistance. In production use, moving to Chroniton Labs soon.

<br clear="left"/>

<img src="https://github.com/chronitonlabs/brand/raw/main/cqlworkbench/cqlworkbench-icon-charcoal-512.png" width="56" align="left" alt="CQL Workbench mark">

**[CQL Workbench](https://chronitonlabs.org/projects/cql-workbench/)**, a desktop application for Apache Cassandra, today AxonOps Workbench. In production use, moving to Chroniton Labs soon.

<br clear="left"/>
