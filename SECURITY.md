# Security policy

This policy applies to every Chroniton Labs project.

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub: open the **Security** tab of the affected repository and choose **Report a vulnerability**. Do not report them in public issues, pull requests or discussions.

Include what you found, the project, branch or version affected, and the steps to reproduce it. We will acknowledge your report, keep you informed while we work on a fix, and credit you when the fix is published unless you ask us not to.

## Vulnerabilities that also affect an Apache project

Some Chroniton Labs projects are built on projects of The Apache Software Foundation, for example ChronitonDB on Apache Cassandra. If the vulnerability also affects the Apache project, please also report it to the Apache Software Foundation security team, following [the Apache security process](https://www.apache.org/security/). We coordinate with the Apache project so that a fix is not disclosed in one project before the other is ready.

## Supported versions

Each project's README says which versions are supported. A project with no releases yet has no supported versions.
